## 📝 Опис застосунку

Програма автоматизує роботу бібліотекаря з книжковим каталогом. Усі дані про книги
зберігаються в одній таблиці бази даних, а взаємодія відбувається через зручний
графічний інтерфейс.

**Що вміє програма:**

- 📖 показувати весь список книг у таблиці;
- ➕ додавати нову книгу;
- ✏️ редагувати дані вибраної книги;
- 🗑 видаляти книгу;
- 🔎 шукати книги за двома критеріями — **назвою** та **автором**.

Усі помилки (немає підключення, незаповнені поля, нічого не знайдено) показуються
користувачу у вигляді зрозумілого повідомлення.

## 🏗 Архітектура MVC

| Шар              | Що містить                                        | Клас               |
| ---------------- | ------------------------------------------------- | ------------------ |
| **Model**        | Дані книги та перевірка значень                    | `Book`             |
| **View**         | JavaFX-інтерфейс у файлі FXML                      | `book-view.fxml`   |
| **Controller**   | Обробка подій UI та повідомлення про помилки       | `BookController`   |
| **Service / DB** | Запити до БД через JDBC, підключення               | `BookService`, `Database` |

Усі SQL-запити виконуються через `PreparedStatement` (без склеювання рядків),
параметри підключення зчитуються з файлу `db.properties`.

---

## 🗄 Схема бази даних

Основна сутність — **Книга**, що відповідає таблиці `books`:

| Поле           | Тип            | Опис                       |
| -------------- | -------------- | -------------------------- |
| `book_id`      | INT, PK, AI    | унікальний ідентифікатор   |
| `title`        | VARCHAR(200)   | назва книги                |
| `author`       | VARCHAR(150)   | автор                      |
| `publish_year` | INT            | рік видання                |
| `copies`       | INT            | кількість примірників      |

SQL-скрипт створення таблиці — [`schema.sql`](schema.sql).
При роботі з H2 таблиця створюється автоматично при першому запуску.

## 🔬 Тема дослідження (Варіант 3): обробка SQLException

`SQLException` виникає під час роботи з базою даних і містить корисну інформацію:
текст помилки, код СУБД (`getErrorCode()`) та код стану `getSQLState()`. У застосунку
помилки аналізуються за `SQLState` і перетворюються на зрозумілі повідомлення
українською, а технічні деталі виводяться в консоль для розробника.
